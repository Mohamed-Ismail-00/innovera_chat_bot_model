# Innovera AI Chatbot 🤖

هذا المشروع عبارة عن مساعد ذكي (Chatbot) مخصص لشركة Innovera، يقوم بالرد على استفسارات العملاء حول الكورسات، الأسعار، الخدمات، وطرق الدفع بشكل آلي وذكي باستخدام نماذج لغوية متقدمة (LLMs).

## 📁 هيكل المشروع

المشروع مقسم إلى قسمين رئيسيين:
1. **Backend (السيرفر):** مبني باستخدام `FastAPI` و `Python` للتعامل مع الذكاء الاصطناعي ومعالجة البيانات.
2. **Frontend (الواجهة):** كود `HTML/CSS/JS` جاهز للدمج داخل أي موقع إلكتروني.

---

## 🚀 كيفية التشغيل (فريق الـ Backend)

هذا الجزء مخصص للمبرمج المسؤول عن تشغيل السيرفر.

### 1. المتطلبات الأساسية
- Python 3.10 أو أحدث.
- مفتاح API من Groq.

### 2. التثبيت والتشغيل
1. افتح الـ Terminal وادخل إلى مجلد `backend`:
   ```bash
   cd backend
   ```
2. قم بإنشاء بيئة وهمية (Virtual Environment) وتفعيلها (اختياري ولكنه مفضل):
   ```bash
   python -m venv venv
   source venv/bin/activate  # في الويندوز: venv\Scripts\activate
   ```
3. قم بتثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
4. قم بإضافة ملف `.env` يحتوي على مفتاح الـ API:
   ```env
   LLM_PROVIDER=groq
   GROQ_API_KEY=your_api_key_here
   GROQ_MODEL=llama-3.3-70b-versatile
   ```
5. تشغيل السيرفر:
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
السيرفر الآن يعمل ومستعد لاستقبال الطلبات على `http://<server-ip>:8000/api/chat`.

## 💻 كيفية الربط بالموقع (فريق الـ Frontend)

هذا الجزء مخصص لمطور الويب لربط واجهة الشات بالموقع الأساسي.

1. **تحديث الرابط:**
   افتح ملف `frontend/js/chat.js`. في الأعلى، قم بتغيير قيمة `API_URL` لتشير إلى الرابط الخاص بالسيرفر الذي تم رفعه في الخطوة السابقة.
   ```javascript
   const API_URL = 'https://api.your-server.com/api/chat';
   ```

2. **نقل الملفات:**
   - انسخ محتويات `frontend/css/style.css` إلى ملف الـ CSS الأساسي للموقع.
   - انسخ ملف `frontend/js/chat.js` واستدعيه في الموقع.

3. **إدراج كود الـ HTML:**
   قم بنسخ كود الـ HTML الموجود داخل `frontend/index.html` (تحديداً الـ button والـ div الخاصين بالشات) وضعهما في الكود المصدري للموقع (مثلاً في الفوتر `footer.php`) قبل إغلاق وسم `</body>`.

## 📝 تعديل بيانات الشركة
إذا أرادت الشركة إضافة كورسات جديدة أو تغيير الأسعار، كل ما عليها فعله هو تعديل ملف:
`backend/app/data/courses_data.json`
وسيقوم الذكاء الاصطناعي بقراءة البيانات الجديدة تلقائياً بدون الحاجة لأي تعديل في الكود البرمجي!
